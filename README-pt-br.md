# Documentação

Esta documentação pertence ao projeto Moonlight Tizen de fidoboy, mantido de forma independente. As páginas ficam neste repositório para que as instruções evoluam junto com o código e as releases.

## Guias do usuário

- [Visão geral dos recursos](Features-Overview-pt-br.md) — recursos do cliente e áudio Dolby pela saída óptica.
- [Guia de início rápido](Quick-Start-Guide-pt-br.md) — primeira conexão com Sunshine ou outro host compatível.
- [Guia de instalação](Installation-Guide-pt-br.md) — instalação do WGT em uma Samsung Smart TV.
- [Guia de atualização](Updating-Guide-pt-br.md) — atualização de outra build ou release anterior deste projeto.
- [Perguntas frequentes](Frequently-Asked-Questions-pt-br.md) — dúvidas comuns sobre controles, áudio e configurações.
- [Problemas conhecidos e limitações](Known-Issues-and-Limitations-pt-br.md) — compatibilidade de hardware, Tizen e Dolby.
- [Guia de solução de problemas](Troubleshooting-Guide-pt-br.md) — verificações para problemas de conexão, vídeo e áudio.

## Desenvolvimento

- [Guia de desenvolvimento](Development-Guide-pt-br.md) — builds locais, artefatos de CI e releases versionadas no GitHub.

Este projeto dá continuidade ao trabalho do [Moonlight Tizen da Brightcraft](https://github.com/brightcraft/moonlight-tizen). A documentação preserva o contexto útil do projeto original e descreve o comportamento e o processo de release desta variante.
