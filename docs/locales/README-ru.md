Эта документация относится к независимо поддерживаемому проекту fidoboy Moonlight Tizen. Страницы хранятся в репозитории, чтобы инструкции обновлялись вместе с кодом и релизами.

- [Руководство по устранению неполадок](Troubleshooting-Guide-ru.html) — проверки проблем соединения, видео и звука.

## Разработка
