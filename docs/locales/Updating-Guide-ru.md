# Руководство по обновлению

## Обновление до новой версии проекта

1. Откройте [страницу релизов](https://github.com/fidoboy/moonlight-tizen-ac3/releases).
2. Скачайте последнюю версию `Moonlight.wgt` или `Moonlight-ForceGM.wgt`, если используете именно этот вариант.
3. Установите её тем же способом, что и ранее (Apps2Samsung, Tizen Studio или соответствующими инструментами устройства).
4. Запустите Moonlight и проверьте, сохранились ли настройки и сопряжённые хосты.

По возможности используйте тот же вариант пакета и тот же способ подписи/установки. Если телевизор не принимает обновление из-за конфликта версии или сертификата, обратитесь к [руководству по установке](Installation-Guide-ru.html).

## Переход с пакета Brightcraft версии 1.18.x на серию 1.0.x этого проекта

Этот проект начинает отдельную последовательность версий с 1.0.0. Поскольку она ниже исходной версии приложения 1.18.x, некоторые телевизоры не позволят обновить приложение поверх старой установки. В таком случае:

1. Запишите настройки, которые нужно восстановить.
2. Удалите старое приложение через менеджер приложений телевизора или инструмент установки.
3. Установите пакет этого проекта и при необходимости заново выполните сопряжение/настройку хостов.

Удаление может стереть локальные данные приложения. Это ограничение связано с отдельной последовательностью версий при сохранении того же идентификатора приложения Tizen; оно не означает, что WGT собран неправильно.

## Обновление экспериментальных сборок

Экспериментальные WGT из GitHub Actions — временные тестовые артефакты. Загружайте файл из соответствующего запуска workflow, а не по старой закэшированной ссылке, и перед установкой проверьте SHA коммита. Не считайте экспериментальный артефакт эквивалентом стабильного релиза с тегом.
