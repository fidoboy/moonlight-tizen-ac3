# Руководство по обновлению

## Обновление до нового выпуска проекта

1. Откройте [страницу релизов](https://github.com/fidoboy/moonlight-tizen-ac3/releases).

2. Скачайте последнюю версию **Moonlight.wgt** или **Moonlight-ForceGM.wgt**, если вы используете именно этот вариант.

3. Установите её тем же способом, что и раньше (Apps2Samsung, Tizen Studio или подходящим инструментом для устройства).

4. Запустите Moonlight и убедитесь, что сохранённые настройки и сопряжённые хосты остались на месте.

По возможности используйте тот же вариант пакета и тот же способ подписи/установки. Если телевизор отклоняет обновление из-за конфликта версий или сертификатов, обратитесь к [руководству по установке](Installation-Guide-ru.html).

## Переход с пакета Brightcraft 1.18.x на серию 1.0.x этого проекта

Этот проект начинает отдельную линейку версий с 1.0.0. Поскольку этот номер ниже исходной версии пакета 1.18.x, некоторые телевизоры могут не разрешить установку поверх существующей версии. В таком случае:

1. Запишите настройки, которые нужно восстановить.

2. Удалите старое приложение через менеджер приложений телевизора или инструмент, которым оно устанавливалось.

3. Установите новый пакет проекта и при необходимости повторно выполните сопряжение/настройку хостов.

Удаление приложения может стереть локальные данные. Ограничение связано с началом отдельной линейки версий при сохранении той же идентичности приложения Tizen; оно не означает, что WGT собран с ошибкой.

## Обновление экспериментальных сборок

Экспериментальные WGT из GitHub Actions — временные тестовые артефакты. Скачивайте артефакт из соответствующего запуска workflow, а не по старому URL из кэша, и проверяйте SHA коммита перед установкой. Не считайте экспериментальный артефакт эквивалентом стабильного выпуска с тегом.
