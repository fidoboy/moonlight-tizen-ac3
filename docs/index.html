Get started

From download to your first stream.

Apps2Samsung is the recommended installation route. Once Developer Mode is enabled, the app catalog can download and install the build for you.

01

Enable Developer Mode on the TV

On the TV, open Home → Apps (and App Settings, if shown), then enter 12345. On a Smart Remote, use its 123 button to open the on-screen keypad. Enable Developer Mode, enter your computer's local IPv4 address as Host PC IP, then restart the TV.

02

Select the Dolby build in Apps2Samsung

Open Apps2Samsung on your computer, select your TV, then choose Moonlight → fidoboy · Dolby in the application catalog. Apps2Samsung downloads and prepares the package; no manual WGT download is needed for this method.

03

Pair your streaming host

Launch Moonlight on the TV and pair it with your PC running Sunshine or another compatible GameStream host. Add the host by its local IP address if it is not discovered automatically.

Compatibility

What you need to know.

TV

Designed for Smart TVs running Tizen OS 5.5 or newer. It has been tested on Samsung TVs; other Tizen-based television brands may differ.

Streaming host

Requires a GameStream-compatible host such as Sunshine, Apollo, Punktfunk, or legacy NVIDIA GameStream where available.

Dolby audio

Requires a host that negotiates AC-3 or E-AC-3, plus a compatible TV and audio receiver. Unsupported combinations continue with Opus where available.
