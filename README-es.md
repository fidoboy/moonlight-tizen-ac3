# Documentación

Esta documentación pertenece al proyecto Moonlight Tizen de fidoboy, mantenido de forma independiente. Las páginas se guardan en este repositorio para que las instrucciones evolucionen junto con el código y las versiones.

## Guías de usuario

- [Resumen de funciones](Features-Overview-es.md) — capacidades del cliente y audio Dolby por salida óptica.
- [Guía de inicio rápido](Quick-Start-Guide-es.md) — primera conexión con Sunshine u otro host compatible.
- [Guía de instalación](Installation-Guide-es.md) — instalación del WGT en un Samsung Smart TV.
- [Guía de actualización](Updating-Guide-es.md) — actualización desde otra compilación o una versión anterior de este proyecto.
- [Preguntas frecuentes](Frequently-Asked-Questions-es.md) — dudas sobre mandos, audio y ajustes.
- [Problemas conocidos y limitaciones](Known-Issues-and-Limitations-es.md) — notas de compatibilidad de hardware, Tizen y Dolby.
- [Guía de solución de problemas](Troubleshooting-Guide-es.md) — comprobaciones prácticas para problemas de conexión, vídeo y audio.

## Desarrollo

- [Guía de desarrollo](Development-Guide-es.md) — compilaciones locales, artefactos de CI y versiones de GitHub.

Este proyecto continúa el trabajo de [Moonlight Tizen de Brightcraft](https://github.com/brightcraft/moonlight-tizen). La documentación conserva el contexto útil del proyecto original y describe el comportamiento y el proceso de publicación de esta variante.
