# Dokumentation

Diese Dokumentation gehört zum unabhängig gepflegten fidoboy-Moonlight-Tizen-Projekt. Die Seiten liegen im Repository, damit sich Benutzeranleitungen zusammen mit Code und Releases weiterentwickeln.

## Benutzerhandbücher

- [Funktionsübersicht](Features-Overview-de.md) — Client-Funktionen und Dolby-Audio über optischen Ausgang.
- [Schnellstartleitfaden](Quick-Start-Guide-de.md) — erste Verbindung zu Sunshine oder einem anderen kompatiblen Host.
- [Installationsanleitung](Installation-Guide-de.md) — WGT auf einem Samsung Smart TV installieren.
- [Aktualisierungsleitfaden](Updating-Guide-de.md) — von einem anderen Build oder einer früheren Projektversion aktualisieren.
- [Häufig gestellte Fragen](Frequently-Asked-Questions-de.md) — Fragen zu Controllern, Audio und Einstellungen.
- [Bekannte Probleme und Einschränkungen](Known-Issues-and-Limitations-de.md) — Hinweise zur Hardware-, Tizen- und Dolby-Kompatibilität.
- [Leitfaden zur Fehlerbehebung](Troubleshooting-Guide-de.md) — praktische Prüfungen für Verbindungs-, Video- und Audioprobleme.

## Entwicklung

- [Entwicklungsleitfaden](Development-Guide-de.md) — lokale Builds, CI-Artefakte und versionierte GitHub-Releases.

Dieses Projekt setzt auf [Brightcrafts Moonlight Tizen](https://github.com/brightcraft/moonlight-tizen) auf. Die Dokumentation bewahrt den hilfreichen Projektkontext und beschreibt zugleich das Verhalten und den Release-Prozess dieser Variante.
